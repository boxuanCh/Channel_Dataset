# TR 38.811 source inventory

The implementation is pinned to 3GPP TR 38.811 V15.4.0 (Release 15), archive
file `38811-f40.zip`. The downloaded source archive has SHA-256
`fff99141ab5f93fcfbca8321de8c4eb48b98347d01c5be53baf5c782308f37b3`.

The implementation covers clauses 6.3 through 6.10: coordinate systems,
antennas, large-scale propagation, flat and frequency-selective fast fading,
Doppler, Faraday rotation, link-level CDL/TDL profiles, and calibration.
TR 38.901 algorithms are shared only through standard-neutral kernels; all
TR 38.811 numerical tables remain separately versioned.

External propagation algorithms are pinned to the editions referenced by the
TR before implementation. Site-specific meteorological and ionospheric data
are caller inputs and are not bundled. Resources remain
`pending_independent_review` until a second transcription review is recorded.

Source: <https://www.3gpp.org/ftp/Specs/archive/38_series/38.811/38811-f40.zip>
